## 参考判据与证据

[任务草稿](tasks-draft.json)绑定原T13文档的选定dev章节及逐轮输入SHA；[参考草稿](reference-draft.json)标记实现者参考、待人工核对，没有真人标签或签名。原文选定章节中的允许数量是**用例声明的预期**，不是当前数据库、某次运行或云端状态。

后续由非出题者、且不参加本轮试用的人核对参考依据和可判定范围。代码独立review不能替代这项人工核对。三维分别记为正确、部分、证据不足、错误；关键错误另列。三维均有证据支持且无关键错误才计完整正确，自报“完成”仍单列。

原E4退出记录及未保存答案不补造，旧标签、题目、封存与预算保持。所有操作停在读取和导航，不创建运行、发送预约Agent、提交业务、生成用例或请求裁判。

## 以后恢复前必须补齐的内容

1. 有实际参与者和非出题者的人工判据核对；记录熟悉程度及题目暴露，不把槽位当真实人。
2. 将候选用例绑定到当时可访问、已审核的dev修订，核对完整原文、预期、内容哈希及真实按钮。当前`case_id`/修订为空，尚未查主库，也没有把历史编号拼成当前入口。
3. 使用新记录器、新来源冻结和独立身份；原T19/T19B入口、期限、源码和账本不能改造重开。新记录器应保留草稿、逐字段错误、原问题先落盘、未知只查回执、明确退出和原记录追加封存。
4. 单独确认实际调用范围、模型/参数和新预算，再初始化独立copilot账本；当前没有账本、approval或执行令牌。

仅供后续讨论的硬上限是copilot总**0.30美元/18请求**，每人一个会话0.10美元/6请求，每题最多2个问题、每问题最多3请求/120秒；单请求45秒/1536输出token，其他角色0。它不是预计费用或完成保证，尚未获批或启用。后续若实现方案或来源变化，重新形成可审阅执行稿；不用日常不限额或旧E4余额代替。

未知调用保留原请求键/预留，不换键或新会话补成功；额度耗尽、失败、未完成和退出照实保留。没有真实对照和足够独立样本，不报告AI增益、统计显著性或通用准确率。
