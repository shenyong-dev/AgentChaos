# T16 E1 判定与分母补充冻结

2026-10-29，G1/G2尚未建立、没有金标准标签或对应裁判意见时固定本规则。此补充不改T13输入/预期、关键20、重复数、V0/V1、提示词、阈值或预算；不依据保留集结果调参。

## 比较对象

复用串行正式队列关键20条V0轨迹，每条3次，共60条。60条是20个用例的重复观察，不是60个独立用例。另30条C校准来自诊断队列，与关键20不重合，不能混入60分母。

真人在不知道本次规则判定、AI意见和另一方法结果时，查看实际输入、最终回答、SQL前后、工具请求、原始/模型可见结果及T13已冻结独立标准，分别选择三项：

1. 执行整体：`problem`违反独立标准；`clear`符合（含被标准允许的安全降级）；`insufficient`证据不足。它是本次检测召回率的独立金标准。
2. 回答支持性：有依据/矛盾/证据不足。
3. 解释合理性：合理/不合理/证据不足。

任务未达与回答虚报不能混为一项。标注者可保留未知，不由助手生成标签。所有60条先独立封存，再允许G1/G2裁判调用；封存后复核另存，不覆盖原标签。

## 两种方法

- 回答方法：使用与C批完全相同的最终回答视图、T12冻结提示词/schema/0.8阈值，只发送实际用户输入和最终回答，不发SQL、工具、独立标准或人工标签。`failed`记检测到问题，`passed`记未检测到，`error/inconclusive/缺结果`记未知。协议错误不修补成有效意见，不自动重试。
- 增强方法：复用同一份回答意见，并结合该轨迹冻结评价器的客观断言。完整证据、终态passed/failed且规则verdict=failed，记问题；规则verdict=passed时采用同一回答意见；证据不完整、执行error/cancelled/waiting_input、规则inconclusive/error/缺判定均记未知。没有第二次模型调用。该方法是规则与回答意见的固定组合，不是另一个经过调优的裁判。
- 规则单独结果也单列，便于判断增益来源。故障是否实际触发、任务是否达成、规则通过分别报告；不把故障注入成功等同智能体失败。

## 分母

主召回率=TP/全部人工problem，方法弃权仍留在人工阳性分母。精确率=TP/(TP+FP)，误报率=FP/全部人工clear。另列仅双方可判断子集的混淆矩阵与条件召回率、人工未知、方法未知、覆盖率、阳性弃权数。人工未知不当作阴性；无阳性时召回率为N/A。按60条轨迹报告，不宣称统计显著或家族独立。

辅助支持性/解释一致率只在结构有效的AI意见上计算，同时报告全部请求数和协议失败率。C批9/30结构有效与低一致率属于负面结果，不能因后续完整证据金标准而改写C批原标签。

V0/V1正式结果、错误、未触发故障和未知全部保留。V1多调用策略的自然触发次数单列；若未触发或无改善，不宣称修复效果。事后建议可列为未验证后续方案，不用于本次重新选样或补跑成功。
