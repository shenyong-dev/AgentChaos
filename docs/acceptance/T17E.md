# T17E 团队验收

本项是全局只读测试助手。当前环境地址、期限、费用和验证结果以docs/evidence/T17E/final-report.md及本地`.local/t17e/latest-review.json`为准。日常5173默认不启用模型，免费指引始终可读。

1. 登录后点击顶栏对话图标，打开“测试助手”。确认显示当前页面和明确选中的开发对象；输入框旁应能看到付费按钮与本会话估算，填入快捷问题本身不调用。
2. 在开发用例详情选择“解释这条用例”，再选择“问助手解释选中内容”，询问测试目的与新建运行方法。引用应有用例修订/指南版本；按钮只能打开原页面或未提交表单，不能自动新建运行。
3. 在环境页询问“为什么不能立即运行”。核对Worker、Dispatcher、版本和预算的实际状态；无回执不等于证明进程已死亡，过期结果不等于当前就绪。助手不能启动服务、改配置或开启其他角色预算。
4. 在一条所属开发执行问“失败在哪里”。点击引用查看SQL、规则和事件快照，再点击“定位证据事件”。应回到同一运行的实际事件；缺SQL不可推断0笔或成功。验收夹具中的离线被测Agent和真实copilot调用方式必须分别标明。
5. 在报告页明确选择两个开发运行，核对比较条件后问“能直接比较吗”。不同种子、知识等条件不能被说成同条件改进；同条件也不是普遍可靠的证明。
6. 换对象或页面后旧讨论应收起；同一对象的状态刷新不能打断正在填写的问题。退出/换账号后不能显示原账号迟到回答或读取原助手回执。
7. 在独立标注/语义复核页只阅读通用指南，不应出现样本问答输入或推荐标签。冻结保留集不能进入开发助手。
8. 查看取证过程与调用明细。断线后查原回执，或按原标识重试，不能换标识重复付费。无模型/失败显示明确状态和基础指引，不能冒充已生成AI结果。未知usage保持预留。
9. 在深浅主题、手机、键盘下打开引用；60秒后应标记历史快照。查看完证据后Esc可关闭提示框，导航后再次打开助手仍能继续安全导航。

完成团队检查后再回复通过及继续；本项不自动开始T17J/K，也不自动提交Git。原T16结论、真人标签、历史账本和封存记录保持。
