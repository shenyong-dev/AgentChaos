入口为 **http://127.0.0.1:5173**，原 5189 的 T17H 临时环境已在导出核验成功后关闭。使用 `demo_operator`；密码读取本地 `.env` 的 `DEMO_SEED_PASSWORD`。审核页面可用 `demo_reviewer` 检查角色边界，不把密码、Cookie 或密钥发到聊天/仓库。

## 怎么检查

1. **逐页看用途。** 打开概览、对象版本、用例库、工作台、运行详情、环境、预约Agent、生成审核、校准、执行语义复核、报告。点击“解释当前页面”或顶栏问号，确认都能回答用途、前置、输入、输出和无数据时去哪；标识应是“基础指引 · 无模型调用”。
2. **从一条用例继续。** 在开发用例库选中一条基础知识用例，点击“解释选中内容”，核对用例编号、修订、对象标识和来源。点击“带入运行配置（不提交）”，应打开已选该修订的向导；不自动预检、创建运行或扣费。非基础知识、不可见或已失效修订应阻塞，不能偷偷换一条。
3. **看懂运行状态。** 打开自己的一次运行，点“下一步”。排队、等待输入、取消、结束的说明应符合实际；“核对规则与SQL证据”“定位执行轨迹”等只切换视图。取消不等于回滚，结束不等于业务成功。别为了验收重复执行或修改旧运行。
4. **了解为何没有AI评价。** 在执行辅助评价页打开基础指引，确认说明刷新仅读取记录，裁判另需校准/开关/预算，AI意见不能代替SQL或规则。输入另一个执行ID但不点击“载入执行”，帮助仍绑定已载入对象；明确载入错误ID后旧说明应撤回。
5. **检查权限和独立标注。** 审核者可以读通用说明，但操作者专用入口应禁用。独立标注未封存时，只能看到操作与通用判据，帮助不分析当前样本、不预填标签、不展示AI答案。不要为本项新增或改写原人工标签。
6. **断网、过期和换页。** API 不可达时，环境页和静态帮助、术语仍可阅读；私有动作不能假装核验成功。打开选中内容等待约30秒，过期后不应继续显示为当前有效；重新核对再使用。快速切页面、换对象或退出后，旧对象/响应不能冒到新页面。
7. **导航与操作分开。** 从指引定位环境 Worker 区块，焦点应落到对应区域；不自动运行 Shell 或重启服务。私有深链会重新核验，失效对象显示原因。创建、预约确认、审核保存、报告导出及付费仍由原页面显式确认。
8. **深浅和键盘。** 检查桌面、768、390和320宽度，抽屉无横向溢出；术语可搜索，Tab/Enter操作，Esc关闭并回到入口焦点。基础指引不应挡住原弹窗或快速跳转。
