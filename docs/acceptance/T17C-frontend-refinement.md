# T17C 前端视觉精修验收

2026-10-31，用户要求依照高级UI设计顾问规范直接调整前端。此项是T17C后的视觉反馈，未开始T17D。运行时代码仅修改`frontend/src/design-system.css`，保留Vue/Element Plus、品牌蓝`#2563eb`与业务逻辑，无新依赖或模型请求。

## 诊断与处理

原页面多个独立卡片权重相近，画布、正文和边框偏蓝，信息层级主要靠边框而非排版区分；概览和表格的空间节奏不一致。本轮采用白色内容区、浅灰侧栏、低饱和辅助色和少量深色说明区，保留产品原有品牌身份。

| 维度 | 原做法 | 本轮实现 |
| --- | --- | --- |
| 配色 | 大面积蓝灰底、多种装饰性图标色 | 白色工作区与浅灰导航，品牌蓝仅强调操作/选中，状态仍保留语义色 |
| 排版 | 数据与普通说明接近同等权重 | 桌面标题30px、手机26px、正文14px；数值采用等宽数字，哈希采用本机等宽字体 |
| 空间 | 四块独立指标卡、每个流程入口再套边框 | 指标整合为一条分栏区域，流程入口用细线分隔，8px/4px间距节奏 |
| 材质 | 边框和投影在各区重复出现 | 6–14px圆角层级、轻双层投影；轻模糊仅用于64px顶部栏，其他内容保持实体背景 |
| 动效 | 交互变化缺少统一节奏 | 核心状态过渡180ms，缓动`cubic-bezier(.2,.65,.3,1)`；支持减少动态效果，取消不必要位移 |

核心Token包括`--ac-radius-*`、`--ac-shadow*`、`--ac-duration`、`--ac-ease`和`--ac-mono`。没有远程字体、循环动画或大面积模糊。过期/未知的服务概览使用中性色，避免背景仍呈绿色成功态。

## 验收步骤

入口：<http://127.0.0.1:5173/workspace>。使用`demo_operator`，密码读取本地`.env`的`DEMO_SEED_PASSWORD`；刷新页面后需重新登录。现有开发服务直接热更新，未重启或终止用户进程。

1. 概览应显示真实指标，数值与后端记录一致；侧栏选中项是白底蓝色标识，收起后仍可按图标与提示导航。
2. 进入开发用例库，使用类别下拉、搜索`T13-N001`，打开“查看用例”。筛选仍生效，弹窗应覆盖顶部栏且内容内部可滚动，Escape可关闭。
3. 按Ctrl/Cmd+K打开快速跳转，搜索“报告”，用方向键与Enter跳转；键盘焦点清晰可见。
4. 在768/390/320px检查概览、手机导航、表格与弹窗。整页不应横向溢出；宽表格在自己的容器内滚动。
5. 工程环境页等待60秒后，原可用标识与成功背景应撤下。阻断`/api/v1/*`后刷新，基础指南仍可阅读。不要阻断`/src/api/client.ts`等前端脚本。
