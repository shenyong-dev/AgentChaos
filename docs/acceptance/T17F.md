# T17F 平台统一登录与会话管理

2026-11-03实施与验证完成，待团队检查。用户本次“开始今天任务，进行下一步”按既定顺序确认T17D并授权T17F；不自动开始T17G/E，不提交Git。本项不需要模型调用。

## 团队检查入口

[打开平台](http://127.0.0.1:5173/workspace)，API为`http://127.0.0.1:8000`。使用本地现有`demo_operator`或`demo_reviewer`，密码读取本地`.env`的`DEMO_SEED_PASSWORD`；不将密码粘贴到聊天或验收记录。主服务已恢复到本项源码，无主Worker，日常四项付费开关保持false。

1. 用操作员登录，依次切换项目概览、开发用例、运行、交互调试、生成、评价、报告；模块不再分别输入密码。刷新页面仍可使用有效会话。
2. 打开已有运行的证据流；另开同源标签退出，两个标签都应回到平台登录，旧轨迹、草稿视图和待创建选择消失。退出不会取消已有运行或删除预约事实。
3. 登录审核员，进入用例审核与评价。再去操作员工作区，应显示权限原因，保持当前身份，不反复要求登录；操作员不能提交审核决定或真人标签。
4. 错误密码应提示账号或密码不正确；闲置30分钟或登录8小时后需要重新登录。退出后旧令牌不可重放。后台事件流/自动重连不能无限延长闲置期限。
5. 手机窄屏及深浅主题下检查登录、身份和退出按钮。退出网络失败时应说明“退出未确认”，可重试；不能声称已经关闭服务端会话。

普通浏览无需付费；不要为验收此登录功能启用模型、创建运行或提交预约。历史T17D临时付费入口已结束，本次没有恢复。

## 实现与兼容

统一身份、角色与退出；MySQL核对账号，Redis保存可撤销会话；HttpOnly/SameSite Cookie、生产HTTPS Secure、Origin和CSRF校验；闲置/绝对期限、限流、跨入口绑定和账号变更失效。前端所有业务HTTP、下载和SSE使用同一身份代次，账号切换中断旧请求，旧响应不能回流；不把密码、Basic头或会话令牌存入Web Storage。

无新表、迁移或依赖。原三条Basic路径保留显式凭据和权限；匿名旧客户端仍取得原错误码/Basic挑战。历史只读恢复仍阻止POST，沿用原Basic只读HTTP或冻结前端，不在历史恢复站点覆盖新登录前端。不同端口/恢复实例不隐式共享登录。

完整权限矩阵、API、来源、期限、回退及限制见[浏览器会话契约](../architecture/browser-sessions.md)。
