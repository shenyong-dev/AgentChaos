# T17C 前端反馈：主题与卡片交互

2026-11-02。用户要求在现有简洁风格上增加卡片反馈和可来回切换的深色模式。本项为 T17C 视觉反馈，不进入 T17D/E，不提交 Git，不新增模型调用。

## 本次调整

原有雾蓝灰侧栏与浅冷灰画布保留为浅色主题。此前只有悬停反馈，页面还存在写死的白色面板，直接反转颜色会影响表格、弹窗和语义状态。

| 维度 | 实现 |
| --- | --- |
| 配色 | 深色画布 `#101823`、卡片 `#182334`、浮层 `#202e43`，侧栏 `#162338 → #111b2a`；品牌蓝 `#2563eb` 保留，深色正文链接使用可读性更高的 `#98baff`。成功、警告、错误分别适配。 |
| 排版 | 沿用已验收的字号、字重、信息密度和留白，深色文本独立设定。 |
| 空间 | 不改变内容结构；桌面主题按钮带文字，窄屏使用太阳／月亮图标。 |
| 材质 | 深色边框和阴影适配侧栏、指标条、表格、候选配置、运行证据、下拉和弹窗。 |
| 动效 | 保留已有悬停层次；真实入口按下缩放 `0.985`、运行行 `0.995`，展开内容 `180ms` 淡入。静态信息卡不伪装成按钮；减少动态模式关闭位移动效。 |

右上角按钮显示当前“浅色／深色”，点击切换。首次跟随系统，手动选择后仅保存 `agentchaos.theme=light/dark`，刷新保持并同步到同源其他标签页。启动前脚本先应用配色，避免等待 Vue 启动后再改变底色。主题偏好保存受限时，当前页面仍能切换并提供状态说明。登录凭据仍只在页面内存中。

使用项目已安装的 [Element Plus 官方深色变量方案](https://element-plus.org/en-US/guide/dark-mode.html)，未增加依赖。新增独立 `theme.css`、主题控制与按钮、预绘制脚本；接入点为 `App.vue` 和 `index.html`。之前已封存的 `design-system.css` 原字节保留。

## 验收步骤

1. 打开 <http://127.0.0.1:5173/workspace>，刷新一次，查看右上角太阳／月亮按钮。点两次，应能在浅色与深色之间往返；刷新后保留最后选择。
2. 用本地演示账号登录，悬停概览卡片；按住“对象版本／开发用例／测试工作台”等入口，应有轻微按下反馈，释放后正常跳转。静态卡片只有边框和阴影反馈。
3. 在“开发用例库”打开类别下拉及“查看用例”：深色下输入、列表、JSON 和遮罩应协调，弹窗位于内容之上，Escape 仍可关闭。
4. 在“工程环境”展开操作条件，查看轻微淡入。系统开启“减少动态效果”后，卡片位移和展开动画应停止；Tab 焦点和空格切换仍可用。
5. 使用 390px、320px 手机宽度检查主题按钮、抽屉导航、表格区域。页面不应产生横向溢出；表格可在自己的容器中滚动。
