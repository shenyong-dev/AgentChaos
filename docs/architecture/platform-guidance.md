# T17I 基础指引与导航契约

## 一份目录，两个读取端

唯一目录为 `backend/app/guidance/catalog.json`，版本 `platform-guide-20261104-v1`。11 类实际页面分别记录用途、前置、输入、输出、空状态和下一步，另有 16 个术语、16 个导航动作。前端导入同一 JSON，服务端读取本地固定文件，不维护两套说明。

目录内容使用递归排序键、UTF-8、无多余空格的 JSON 计算 SHA256。前端 Web Crypto 与服务端 canonical_hash 核对；请求目录不匹配返回 409，要求刷新。目录属于源码绑定：Agent 配置 manifest 与 Worker 指纹同时包含 app 内 JSON；这次兼容版本变化不代表被测 Agent 质量提升。

前端 Docker 构建明确复制目录到与源码相对路径一致的位置，最终只有编译产物进入 nginx 镜像。已用独立 D 盘源码包与带标记的控制目录验证打包确实读取复制文件；使用现有缓存依赖，没有构建/拉取 Linux 镜像，不能将此检查称为完整容器部署验收。

## 帮助界面

所有实际路由都有“解释当前页面 / 解释选中内容 / 下一步”，顶栏保留统一入口。抽屉提供页面说明、选中内容、下一步、术语；明确标为“基础指引 · 无模型调用”。未登录、API 不可达时仍可读静态说明和术语，只有公共环境导航可直接本地跳转；私有动作无法核验时说明原因。

对象来自当前页面已经选择或显式载入的标识，不把未提交的文本框内容当作对象。组件所有者、完整路由与身份代次共同绑定选中内容；页面/对象切换、退出或换账号会取消旧请求，旧响应、错误和 finally 不覆盖新状态。报告仅在报告视图说明已加载运行；会话、运行还需匹配当前路由。对象标识和依据引用显式显示。

动态观察只核对身份及所选对象的元数据，**不等于基础服务、模型或队列已就绪**。有效期 30 秒；未知、失败、过期撤回对象说明。环境健康与 Worker 状态仍由原页面的实际检查提供。每次点击私有导航重新向服务端核验，不使用缓存观察直接放行动作。

## 只读 API

- `GET /api/v1/guidance/context`：GuideContext 查询模型；页 ID、目录哈希、可选对象 kind/id。
- `GET /api/v1/guidance/actions`：GuideAction 查询模型，增加动作 ID；返回 navigate_only、固定路由、对象引用与到期时间。

沿用 HttpOnly 会话/Origin 身份协议及 Basic 兼容，数据库重新检查账号启用和角色。拒绝额外字段、任意 URL、Shell、用户 ID、标签、审批或执行参数。对象类型必须属于当前页面，整数/UUID 分别严格解析。API 不初始化模型预算、不调用模型、不创建运行或导出报告。

后端检查对象所有权、可见性、开发修订及知识条件；前端再次核对动作 ID、对象、目录哈希、有效期及精确路径/查询/锚点。环境公共动作只使用本地已实现目录，不接受动态 URL。未知、已删除、归属改变、版本或条件变化均返回明确原因。

## 动作范围

| 类别 | 动作 | 结果 |
|---|---|---|
| 页面 | `page.*` | 导航到已实现的固定页面；角色仍校验 |
| 环境 | `environment.worker` | 定位 Worker/Dispatcher 检查区块；不启动服务 |
| 用例 | `case.read` | 经复核打开指定已审核开发修订的说明 |
| 用例 | `case.prepare` | 经复核带入未提交配置；预检与创建仍需用户操作 |
| 运行 | `run.trace` / `run.assertions` / `run.semantic` | 打开自有运行对应视图；不执行、恢复、确认或调用裁判 |

用例深链到达后再次校验，而非信任地址参数。表单沿用 T17H 原回执和预检协议；本功能不更改未知创建结果的处理。锚点只允许两个已实现区域，异步载入时有界等待并定位焦点，失败说明未加载，不无限等待或执行选择器字符串。

## 受保护内容

用例说明复用 T17G 开发集可见性及原修订哈希；待审、校准、保留用例不进入开发解释。运行帮助只说明状态与流程，不带入输入、回答或样本内容。

校准/生成批次只读取有权限的 Artifact 元数据。未封存校准批次仅说明独立标注步骤；不调用 JudgeService._rows，不打开样本、标签或 AI 结果文件，不推荐答案。封存后仍只说明阶段，复核保留原标签。测试用不可读取文件路径的实际 SQL Artifact 验证该边界；浏览器独立标注场景使用明确标注的模拟样本视图，不冒充新的真人标注或校准。
