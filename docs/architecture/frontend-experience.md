# T15 前端整体体验调整

2026-10-29用户要求按本地《资深前端交互与视觉体验优化专家》文档直接调整页面，作为T15反馈实施。没有进入T16，没有新增模型调用或Git发布。继续使用Vue3/TypeScript/Element Plus；没有新增包、字体下载或后端接口。

## 问题分析

原页面的次级文字大量只有9—12px；灰绿配色同时承担背景、正文、主操作与状态，扫读时难以区分。统计、筛选和内容经常直接平铺，表单和原生下拉与Element Plus控件的尺寸不一致。证据详情的信息密度高，但标题、状态、预期和实际的层级不够清楚。

改造前真实截图保留在`docs/evidence/T15/frontend-redesign/before/`，包括概览、开发库、环境、报告及执行证据。截图来自已认证的真实只读页面，没有补造运行或成绩。

## 布局与展示优化

| 调整 | 具体取值或实现 | 为什么改 / 预期效果 |
| --- | --- | --- |
| 统一颜色 | 主色`#2563EB`，画布`#F4F6FB`，正文`#42536D`，标题`#17253E`，次级文字`#607089` | 主操作、正文、辅助信息能被快速区分 |
| 语义色 | 成功`#147D64`、警告`#986600`、错误`#C23B45`，未知保持中性色 | 颜色表达实际状态，配合中文文字，不只靠颜色传递结果 |
| 排版 | 正文14px，表格13px，次级信息通常12px，主标题28px/手机25px | 提高中文与长记录的可读性；代码/哈希继续使用等宽字体 |
| 间距与边界 | 内容间隔16/24px，主内容桌面边距36px/手机18px，卡片圆角12px、控件8px | 建立稳定层级，减少内容堆叠感 |
| 概览 | 四张独立指标卡、按数据来源显示原计数；实验流程入口与执行条件分区 | 第一屏能看清运行、用例、对象和下一步入口，0仍显示真实0 |
| 表格与证据 | 浅色表头、行悬停、筛选工具栏、预期/实际对照、代码区独立底色 | 在较密集的信息中保持定位能力 |
| 导航 | 白色分组侧栏、蓝色当前态、统一图标，保留桌面折叠与手机抽屉 | 保持八入口的归属清楚，减少查找成本 |

主题入口为`frontend/src/design-system.css`；旧共享CSS及五处局部样式统一引用主题变量，避免旧绿色与新主题混用。共13个原生select改为现有Element Plus Select/Option，保留v-model、数值/字符串类型、选项值、disabled与change处理。类别“全部”和“无故障”仍保留空字符串的原有含义；空批次显示中文提示；人工标签仍无预填。

参考：[Element Plus主题机制](https://element-plus.org/en-US/guide/theming.html)用于组件变量定制；[Carbon表格规范](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)用于工具栏/表格/分页层次；[Langfuse折叠导航](https://langfuse.com/changelog/2024-11-01-collapsible-sidebar)用于紧凑导航组织。只借鉴组织方式，未复制第三方界面源码或引入其框架。

## 交互与点击优化

- 新增可实际使用的快速跳转：点击顶栏搜索，或Ctrl/Cmd＋K；支持按页面名称/功能/路径筛选，方向键、Enter、Esc和焦点返回。只切换既有路由，不发起测试或模型请求；已有弹窗活动时不抢占快捷键。
- 按钮统一150ms颜色/阴影过渡与轻微按压反馈；禁用、加载、悬停、焦点各自明确，遵守减少动态效果设置。登录加载期间禁用输入并拦截重复提交，原认证数据流保持。
- 弹窗沿用Element Plus的Overlay与焦点管理；统一限高、正文滚动、固定可见的操作区，避免故障条和筛选区盖住确认操作。没有通过手调高z-index绕过组件管理。
- 手机选择器与下拉面板限宽，长选项可换行；表格在自己的容器内横向滚动，页面整体不横向溢出。窄屏导航、快速跳转和操作按钮都有可操作区域。
