# 全局测试助手契约

T17E复用T17I目录与全局抽屉。平台助手copilot和被测预约Agent、生成器、裁判分别配置、提示词、会话及预算。打开抽屉、切页、填入问题和阅读基础指引均不调用模型，只有明确点击“询问AI（付费）”才请求。

## 会话和取证

`GET /api/v1/copilot/access`读取开关和本角色账本。`POST /sessions`建立绑定当前身份、登录会话、页面、目录hash、明确选中对象及可选比较运行的助手会话；不会创建实验。`POST /sessions/{id}/messages`提交带request_id和context_hash的问题；同标识同问题重放原回执，不能换问题。`GET /sessions/{id}/messages/{request_id}`仅查回执，不再次调用。初始创建无模型请求。

Redis命名空间绑定实际SQL目标与执行namespace，助手会话绝对8小时、最多12轮。浏览器原身份会话仍按T17F的30分钟闲置/8小时绝对期限校验，助手并不延长其权限。退出、账号权限改变、助手版本变化、对象删除/归属变化时拒绝原会话。前端按身份代次、路由与对象标识撤回迟到响应；同一对象的后台刷新不重置讨论。

有界只读工具不接收目标参数：当前页指南、选中对象、当前环境前置、所属开发执行的SQL/规则/事件快照、明确选择的两运行比较。每轮最多3个模型请求、总120秒；单请求最多45秒，使用可取消异步流总截止。只保存真实usage，超时/缺usage保留未知预留。证据有大小上限；截断明确标记，不把预览当全量。执行证据优先读取首4条错误与最近8条事件、最多4个执行，不声称完整轨迹。

每份来源包含source_id、采集/过期时间、内容hash、目录版本与受控定位信息。服务端验证本轮引用存在及导航ID权限；前端再由T17I动作契约核验固定路由。事件定位还要通过原事件接口复核运行归属、事件ID及完整性，才能追加定位参数。过期来源只显示历史快照，跳转重新核验，不自动再调用模型。

## 安全与结论边界

所有自由文本在存储/模型前脱敏；首消息只带脱敏的最小对象元数据，不绕过工具来源清洗。用户问题、日志、工具输出、用例输入均是不可信数据，不能改变工具或权限。没有Shell、任意文件、网络搜索、任意SQL或任何业务写工具。验收SQL账号实际只有自有库SELECT；HTTP写白名单仅登录退出和助手请求。

开发用例按原审核/家族/集合保护读取，校准和保留集不进入开发分析。校准及独立语义复核页只提供通用指南，问题和样本均不发模型；不读标签/AI文件，不推荐标签。生成批次和预约调试会话只提供既有受权元数据，不借用业务工具。

回答区分观察事实、可能原因、缺失证据和下一步。事实/推测/建议引用本轮实际来源；未知引用或动作使整份回答失效，保留原调用与错误。来源存在和完整性验证不能证明语义支持；界面始终标记AI解释待核对。运行结束、规则通过、目标达成、SQL事实与AI评价不合并成新权威分数。
