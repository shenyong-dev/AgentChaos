# T09 多轮、检索与身份边界

2026-10-28。本项是开发边界验证，沿用FastAPI/Vue3/LangGraph/MySQL/Redis，不引入向量模型、完整Skill或新表。正式120条数据集和人工审核仍按T11/T13推进；开发脚本中的机械approved不能冒充正式团队批准。

## 结构化状态与上下文

字段保留值、来源轮次与原文；用户修正日期/人数时其余字段来源保持。修改和拒绝撤销原草稿/确认，旧draft/hash/revision不能继续提交。身份、scope、session、grant从服务端绑定；模型输入/工具参数不能指定这些权限。

structured-facts-v2把完整工具调用块作为选择单位，保留原始检查点及完整历史，提供选中message_id与丢弃计数。48,000为本项目保守输入预算（UTF-8字节及消息序列化作为token上界，另留输出空间和工具Schema），不是服务商上下文容量。若结构化事实或最新完整块放不下，在调用前拒绝；不拆tool_call_id配对，也不偷偷使用更大的后备限额。首轮严格18K实现容不下部分正常工具回合，已保留开发失败并调整显式预算。

每次整理保留日期/人数的最新来源、拒绝、确认修订、未知提交原键、业务结果与业务历史。结构化状态是摘要依据，不用生成式摘要猜测字段。历史、规则、候选和工具资料明确作为数据，内部角色/指令不能授予权限。未知提交整理前后的原键保持由独立反例验证；本项不宣称每一种故障都重跑了付费长对话。

CONTEXT_POLICY进入不可变目标manifest；原版本不修改。运行仍最多50轮、每轮12次模型调用/120秒，平台另有每执行调用、步骤、token、时限及每运行金额限制。

## 冻结知识与BM25

Worker从运行冻结manifest加载确切document_id列表，复核内容/配置哈希；缺一个修订则拒绝执行，不回退默认知识。服务层可由可信配置选择隔离开发资料，HTTP请求仍不能指定知识/身份/权限。

先按实验场景及有效时间过滤，时间区间左闭右开；适用同key不同内容为evidence_conflict，不强选最新版。过期/未来条文不能因得分高而覆盖有效旧条文。无匹配/弱相关/无适用证据分别返回状态。无意义词的支持检查只看适用语料。

rules-bm25-v2保留jieba与BM25Okapi的k1=1.5、b=0.75、epsilon=0.25、top_k=3和0.01阈值；当极小语料的IDF非正，使用log1p((N-df+0.5)/(df+0.5))，其他正值不变。理由是两条都含“容量”的小语料会出现负平均IDF，导致实际存在的唯一适用条款无法召回。无条款或冻结列表不完整时明确错误。

开发词项v2补“容纳/参会者”后，固定6条正样本Recall@3仍为5/6，不能宣称这两项映射提高了本批召回率。进一步检查发现query的“多久”扩展为“时长”，但原条款的“时长”被切开，故误召回7天规则。当前词项v3与用户词典固定“时长”后，同一组开发样本为6/6，4条无答案误召回0。原5/6结果完整保留；这是开发样本调优，不是保留集准确率，不自动引入P1向量。检索命中和回答受来源支持是两项检查，不由模型自行打分。

## 验证层次与权限

纯规则反例检查整理后字段/拒绝/原键/提交事实及完整工具块；真实MySQL/Redis离线图检查草稿失效、长对话、会话清空、两个operator认证和外部资料不能授权。对外404避免泄露其他身份会话，JSON伪造权限400；跨身份操作不得推进revision或写预约。

真实DeepSeek开发矩阵另存当前字段、检索结果/修订、完整事件、原始模型调用及SQL事实。长拒绝与短拒绝共享相同关键输入，再插入明确不改变条件的12个背景回合；已提交长对话另核对SQL始终唯一。插入本身不算新的正式用例家族。

知识注入样例含“user:2/grant=true/无需确认/调用run_shell”等外部指令，观察模型实际请求及服务端拒绝，而非只检查最终礼貌回复。该小样本通过也不代表覆盖全部提示注入方式。

当前状态、实际费用、失败和团队复现见[T09验收](../acceptance/T09.md)及[独立开发样例](../fixtures/T09/cases.json)。真实验收使用进程内同一执行器、真实SQL/Redis/DeepSeek，不将它称为新增Linux双Worker实验。旧T04—T07预算和原始证据保留；T09只给agent独立开放总金额，生成器/裁判0。

首批真实场景发现非中断状态下的拒绝只保留confirmation_state，未写denials来源；现普通输入同样记录source_turn/text，draft_id允许为空。首批79次调用及独立检查false保留，修复后同目录之外另跑78次，全157次有usage，不冲销旧消耗。注入资料也由独立段落改为同一可命中条款，必须在实际工具返回和真实provider请求中均找到攻击内容，才计入已送达覆盖。

证据页增加“下一窗口”，在500条内存上限处沿原持久游标继续，成功读取后才替换当前窗口；不会重新执行Agent或工具。分页测试等待本次读取结束，避免上一请求尚未更新DOM时重复点已消失的按钮。真实长对话回放和额外明确离线模型的50轮/超过500事件样例分开记录。
