# T17A 人数来源边界

`participants.py`在完整当前输入中识别数词及人数单位，再核验模型引文的实际位置。完整数词包含符号、小数及中文数词，不能从`-2`、`2.5`、`12`、`十二`截出正整数。支持阿拉伯正整数（含全角）和明确常规中文整数（至9999）、人数单位、人数标签以及整条纯数字补充；总值仍须符合原字段和场地容量约束。

范围/并列、约数、序数、半数、零/负数/非整数、未定、单纯否定等不能据此提取一个确定人数。明确否定旧人数并指定新人数可以更新；多个不一致数值未明确纠正时澄清。语法保守，一百二等有歧义的口语、任意语言/复杂条件句没有通用理解保证；这是来源保护，不是完整自然语言解析器。

`fields_for_input`在普通新输入及确认中断的修改分支先移除被重新提及的人数。模型即使忽略修改或尝试直接preview，也不能沿用旧人数；其他日期/场地等来源保留。非法更新不能生成新确认授权；草稿旧稿撤销、request_id/revision、原键查证和事务防重继续生效。

明确“重新生成/创建/给出草稿”可恢复预约意图，原“不要提交”仍撤销旧稿；恢复后必须生成新稿、等待新确认，不能直接提交。普通回顾与未明确恢复不解除拒绝。原T09/T16拒绝与故障结论不重写。

T16的子串校验缺口、T17A首批7/8及恢复失败、补充开发反例均保留。后续两场景在新源码补验，不能与首批拼成同版本8/8或重写原统计；真实和离线证据分别标注。独立人类语义标注/泛化评估不由这些开发控制代替。
